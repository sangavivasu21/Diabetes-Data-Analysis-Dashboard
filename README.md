# Diabetes-Data-Analysis-Dashboard

Project Overview

This project analyzes a healthcare diabetes dataset using Tableau Public. The dashboard explores patterns in glucose levels, age groups, BMI, and diabetes outcomes.

Three key findings
You can use these findings in your assignment report. The first is directly supported by your chart; verify the others against your completed visualizations.
1. Glucose and diabetes outcome: The average glucose level is higher for Outcome 1 (141.26) than Outcome 0 (109.98) in this dataset.
2. Age-group distribution: The number of records differs across age groups, with more records in some younger age groups than in the older groups shown.
3. Health-variable relationship: Comparing glucose and BMI may reveal whether these variables tend to vary together and how their distributions differ by diabetes outcome. State the direction of any relationship only after checking the scatter plot.

Suggestions and recommendations
- Suggestion 1: Encourage regular health screenings and glucose monitoring, especially when other risk factors are present.
- Suggestion 2: Improve the dashboard with interactive age and BMI filters so users can explore different subsets of records.

Conclusion
The dashboard explores diabetes-related patterns in glucose levels, age groups, BMI, and recorded outcomes. The comparison shows a higher average glucose level among records with Outcome 1. Interactive filters can make these patterns easier to explore. The results describe this dataset and should not be treated as proof of causation or as a medical diagnosis.
